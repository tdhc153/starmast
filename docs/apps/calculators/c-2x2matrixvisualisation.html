Calculator: 2x2 matrix visualisation

Author

Tom Coleman, Ross Mcphee

Summary
A calculator to provide visualisations for what a \(2\times 2\) matrix does to vectors in 2D space.
2×2 matrix visualiser
Matrix A

Enter four numbers into the entries of the matrix A, then select Apply matrix to draw the images Ai and Aj of the unit vectors i and j.

[
]
A = [[1, 0], [0, 1]]
